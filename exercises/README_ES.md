# Resumen de los ejercicios del curso

```{admonition} Regla de oro
:class: important
Siempre **intenta el ejercicio por tu cuenta** antes de consultar la solución. ¡El esfuerzo en resolver un problema es donde ocurre el aprendizaje!
```

## Temas

::::{grid} 1 1 2 2
:gutter: 3

:::{grid-item-card} **Ejercicio 1** ⁉️ [Conceptos básicos de resistividad](Exercice1_ResistivityBasics_ES.md)
:class-header: bg-light

Comprende cómo varía la resistividad con el tipo de material y el contenido de humedad.

**Debate:**
- ¿Por qué afecta el contenido de humedad a la resistividad?
- ¿Cómo puede influir esto en los sondeos TRE?
:::

:::{grid-item-card} **Ejercicio 2** ⁉️ [Diseño de sondeo TRE](Exercice2_ERTSurveyDesign_ES.md)
:class-header: bg-light

Diseña un sondeo TRE para un escenario dado, incluyendo el espaciado de electrodos, la longitud del perfil y la secuencia de adquisición.

:::

:::{grid-item-card} **Ejercicio 3** ⁉️ [Análisis de datos de campo](Exercice3_FieldDataAnalysis_ES.md)
:class-header: bg-light

Analiza datos de campo reales o sintéticos de sondeos TRE y EM, incluyendo la inversión.

:::

:::{grid-item-card} **Ejercicio 4** ⁉️ [Interpretación de datos de campo](Exercice4_FieldDataInterpretation_ES.md)
:class-header: bg-light

Analiza datos reales y realiza la interpretación.

:::
